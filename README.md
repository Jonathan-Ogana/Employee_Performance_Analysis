# Employee Performance Analytics Dashboard

## Overview

This project presents an interactive **Employee Performance Analytics Dashboard** built in Microsoft Excel. The dashboard enables HR managers, team leads, and executives to monitor workforce productivity, attendance, performance trends, and promotion outcomes through a single reporting interface.

The solution transforms employee data into actionable insights that support performance management, workforce planning, and strategic decision-making.

---

## Business Problem

Organisations often struggle to consolidate employee performance metrics into a single view that supports data-driven decision-making.

Without a centralised reporting system, management may find it difficult to:

- Identify top-performing employees
- Track departmental productivity
- Evaluate attendance impact on performance
- Monitor promotion effectiveness
- Compare performance across job roles and work locations
- Detect workforce trends over time

This dashboard addresses these challenges by providing a comprehensive performance monitoring solution.

---

## Objectives

The dashboard was developed to:

- Analyse employee performance across departments
- Monitor attendance and productivity metrics
- Compare performance across job roles
- Evaluate performance trends over time

## Dashboard Features

The dashboard provides a high-level overview of key workforce metrics:

- Average Performance Score
- Average Attendance Rate
- Total Tasks Completed
- Average Manager Rating

### Department Analysis

Performance comparison across:

- Sales
- Marketing
- IT
- HR
- Finance

### Job Role Analysis

Performance comparison across:

- Analyst
- Associate
- Developer
- Executive
- Manager

### Performance Distribution

Visual representation of:

- High Performance Employees
- Medium Performance Employees
- Low Performance Employees

### Attendance Analysis

Evaluates the relationship between attendance rates and employee performance.

### Work Location Comparison

Compares performance among:

- Hybrid Employees
- On-site Employees
- Remote Employees

### Promotion Analysis

Examines the relationship between employee promotions and performance outcomes.

### Employee Ranking

Highlights the top-performing employees based on task completion metrics.

### Monthly Performance Trends

Tracks workforce performance throughout the reporting period.

---

## Key Insights

The analysis revealed several important findings:

- Hybrid employees recorded the highest average performance scores.
- Employee productivity varies significantly across departments and job roles.
- Attendance appears to have a positive relationship with performance outcomes.
- A relatively small group of employees contributes a significant share of completed tasks.
- Promotion history shows measurable differences in performance performance levels.

---

## Business Recommendations

### 1. Strengthen Hybrid Work Policies

The analysis indicates that hybrid employees achieve strong performance outcomes. Management should further investigate and optimise hybrid work arrangements.

### 2. Target Low-Performing Segments

Departments and employee groups with lower performance scores should receive additional coaching, mentoring, and development support.

### 3. Improve Attendance Monitoring

Attendance has a noticeable impact on productivity. Early intervention programmes can improve employee engagement and overall performance.

### 4. Recognise High Performers

Top-performing employees should be recognised through rewards, promotions, and retention initiatives.

### 5. Review Promotion Criteria

Promotion decisions should continue to be aligned with measurable performance indicators to support organisational effectiveness.
